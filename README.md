## 🌟 Overview

South Glass & Aluminium Works is an established architectural glass and precision aluminium fabrication company operating from Five Star Road & Muhoho Avenue in Nairobi. This repository contains the complete, high-performance web application featuring:

- **Residential Glass & Aluminium Works:** Frameless glass balcony balustrades, custom master bathroom shower cubicles, acoustic soundproof double-glazed windows, and modern aluminium sliding patio doors.
- **Showcase Residences & Stays:** The living residential showcase on Muhoho Avenue where clients and international travelers can experience our architectural glass installations and luxury short-stay hospitality in person.
- **Interactive 360° Panorama Explorer:** Real-time architectural viewer with daytime, golden hour sunset, and evening skyline lighting modes.
- **Acoustic Double-Glazing Simulator:** Interactive audio demonstration of 42dB noise attenuation comparing open street levels with sealed residential sanctuary interiors.
- **Tactile Sound & Haptics Engine:** Web Audio API synthesizer emulating smartphone vibration buzz and crystalline glass acoustic chimes.
- **SEO & Google Search Console Pillar Guides:** Deep articles targeting high-intent commercial keywords for residential glazing and luxury serviced residences in Nairobi.

## 🏗️ Core Residential Offerings

1. **Frameless Glass Balcony Balustrades:** 12mm to 17.52mm laminated toughened safety glass embedded in concealed floor-mounted aluminium shoe channels.
2. **Bathroom Shower Glass & Cubicles:** Custom walk-in wet room screens, fluted spa glass partitions, and frameless corner shower cubicles with anti-limescale coatings.
3. **Acoustic Double-Glazed Windows:** Thermally broken aluminium frames with dual 6mm laminated panes separated by an argon-gas acoustic barrier reducing noise by 42dB.
4. **Aluminium Sliding & Folding Patio Doors:** Heavy-duty bi-fold accordion doors and slim-profile multi-track sliding systems with sunken flush threshold tracks.
5. **Bespoke Mirrors & Custom Frames:** Modern pill-shaped, oval, round, and backlit LED vanity mirrors manufactured to custom dimensions.

## 🚀 Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS v4 with dual theme support and custom glassmorphism utilities
- **Motion Graphics:** `motion` (Framer Motion v12)
- **Icons:** `lucide-react`
- **Audio & Haptics:** Custom Web Audio API synthesizer + `navigator.vibrate`
- **SEO:** OpenGraph, Twitter Cards, Semantic HTML5, and Schema.org JSON-LD structured data for `LodgingBusiness`, `VacationRental`, and `LocalBusiness`

## 🛠️ Getting Started

```bash
# Clone the repository
git clone https://github.com/harrykashigan-sys/south-glass-and-aluminium-works.git

# Navigate to the project directory
cd south-glass-and-aluminium-works

# Install dependencies
npm install

# Start the local development server
npm run dev

# Build for production
npm run build
```
